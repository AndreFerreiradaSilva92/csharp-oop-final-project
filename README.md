# C# Employee Management System

Console-based Employee Management application developed in C# as part of an Object-Oriented Programming (OOP) project.

## Features
- Employee Registration with unique ID validation.
- Data listing and search by ID.
- Allowance (Plafond) management.
- Salary analytics (average, highest, lowest).
- Benefits tracking (health insurance).

## Technologies
- Language: C# (.NET)
- Paradigm: Object-Oriented Programming (OOP)
- Version Control: Git & GitHub

## How to Run
Open the project folder in your terminal inside VS Code and run:
dotnet run
